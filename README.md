# volando.uy - Plataforma de Gestión de Vuelos

Proyecto académico full stack desarrollado durante el segundo semestre de 2025 por un equipo de 5 estudiantes de la carrera Tecnólogo en Informática (UTEC).

## Descripción General

volando.uy es una plataforma de gestión y reserva de vuelos desarrollada en múltiples iteraciones, aplicando conceptos de ingeniería de software, arquitectura distribuida y desarrollo empresarial en Java.

El sistema permite la administración de rutas de vuelo, vuelos, reservas, paquetes promocionales y usuarios, incluyendo funcionalidades web, escritorio y móviles.

---

# Arquitectura del Sistema

La plataforma fue dividida en múltiples componentes:

* Servidor Central
* Aplicación de Escritorio (Swing)
* Aplicación Web
* Aplicación Web Responsive para móviles
* Servicios Web

La arquitectura evolucionó progresivamente a lo largo de tres grandes iteraciones del proyecto.
